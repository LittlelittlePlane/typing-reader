# 📖 Typing Reader

**通过打字，重新发现阅读的乐趣。**

Typing Reader 是一款免费、轻量的网页打字阅读器。它将传统电子书阅读与打字练习结合起来，让你通过逐字输入的方式阅读书籍，在享受文字的同时提升打字熟练度与专注力。

无需注册账号，无需安装软件。打开网页，导入一本喜欢的书，就可以开始阅读。

## ✨ 主要功能

### ⌨️ 沉浸式打字阅读

- 直接在原文上输入，无需额外的输入框。
- 正确输入的文字显示为绿色，错误输入显示为红色。
- 支持中文输入法，候选框跟随当前输入位置。
- 支持段落重输、跳过、暂停和进度保存。
- 支持鼠标滚轮、方向键和鼠标拖动回看内容。
- 章节完成后自动进入下一章。
- 实时统计输入字数、正确率和打字速度。

### 📚 多格式电子书导入

支持以下文件格式：

| 格式 | 支持情况 |
|---|---|
| TXT | ✅ 支持 |
| EPUB | ✅ 支持 |
| DOCX（Word） | ✅ 支持 |
| PDF | ✅ 支持文字型 PDF |

导入时会尝试自动识别章节、小节与文档结构，并提供：

- 章节名称修改、拆分与合并。
- 多级标题识别。
- 前言、目录和版权页的分类处理。
- PDF 重复页眉、页脚及页码过滤。
- 正文编号列表与章节标题区分。
- 章节预览和手动调整。

> 自动章节识别并非完全准确，复杂排版的文档可能需要手动调整。扫描版 PDF 暂不支持 OCR。

### 🗂️ 本地书架管理

- 管理已导入的书籍。
- 按章节选择阅读内容。
- 独立保存每本书、每个章节的阅读进度。
- 支持删除书籍和单独删除章节。
- 支持较长篇幅的电子书，按需加载正文，减少页面卡顿。

### ✍️ 自由创作

Typing Reader 不仅可以阅读，也可以写作。

- 创建自己的作品。
- 自由添加和编辑章节。
- 自动保存创作内容。
- 将章节导出为 TXT。
- 使用打字阅读模式重新阅读自己的作品。

### 🎨 个性化阅读体验

- 浅色和深色主题。
- 可调节正文字号。
- 简洁、专注的阅读界面。
- 固定顶部导航栏。
- 可隐藏的章节目录。
- 桌面端与移动端自适应布局。

## ⌨️ 快捷键

| 快捷键 | 功能 |
|---|---|
| `Backspace` | 删除错误输入或回退字符 |
| `Tab` | 重新输入当前段落 |
| `Enter` | 在当前段落输入完成后确认并继续 |
| `Shift + Enter` | 跳过当前段落，标记为黄色 |
| `↑ / ↓` | 平滑上下滚动 |
| `Esc` | 暂停 / 继续打字 |

也可以使用鼠标滚轮或拖动页面浏览之前的内容。回看不会改变当前打字进度。

### 本地使用

1. 下载项目中的 `index.html`。
2. 使用 Chrome、Edge 或其他现代浏览器打开。
3. 阅读内置的《Typing Reader 使用指南》，熟悉操作。
4. 从书架导入自己的电子书，选择章节，开始打字阅读。

本项目采用单文件 HTML 结构，无需安装 Node.js 或配置后端服务器。

部分文件解析功能可能需要联网加载第三方 JavaScript 组件。

## 🌐 使用 GitHub Pages 部署

你可以将 Typing Reader 免费部署到 GitHub Pages。

1. Fork 本仓库，或创建一个新的公开仓库。
2. 确保网页主文件命名为 `index.html`，并位于仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和 `/(root)` 目录。
6. 保存设置，等待 GitHub Pages 完成部署。

部署后，通常可以通过以下格式的网址访问：

`https://你的用户名.github.io/typing-reader/`

具体地址以 GitHub Pages 显示的链接为准。

## 🔒 隐私与数据存储

Typing Reader 采用本地优先的设计。

- 电子书内容在用户浏览器中解析。
- 不需要注册账号。
- 不提供云端账户同步。
- 书籍、阅读进度和自由创作内容主要保存在浏览器的 IndexedDB 中。
- 应用本身不提供将私人电子书上传至后端服务器的功能。

如果浏览器无法使用持久化存储，程序会尝试进入临时内存模式，以便继续阅读和创作。

**请注意：**

- 清除浏览器网站数据，可能导致已保存内容丢失。
- 临时模式下的数据在刷新或关闭页面后可能丢失。
- 不同浏览器或设备之间的数据不会自动同步。
- 重要创作内容请及时导出备份。

## ⚠️ 已知限制

- 扫描版 PDF 暂不支持文字 OCR。
- PDF 自动分章可能受到复杂排版、页眉页脚和文本提取顺序的影响。
- 超大文件的解析速度与浏览器内存有关。
- 不同操作系统与中文输入法的兼容性可能有所差异。
- 当前没有用户账户和跨设备同步功能。
- 部分文件解析组件需要网络连接。

## 🛠️ 技术实现

本项目主要基于：

- **HTML5**：页面结构。
- **CSS3**：页面布局、主题和响应式设计。
- **JavaScript**：打字引擎、章节导航和业务逻辑。
- **IndexedDB**：浏览器本地书籍与进度存储。
- **PDF.js**：PDF 文字提取。
- **浏览器文件处理 API**：本地文件读取与导入。

目前使用单文件网页架构，便于部署、测试和迭代。
